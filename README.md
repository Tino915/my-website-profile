## 📁 Project Structure

The portfolio can be organised using the following structure:

```text
portfolio/
│
├── index.html
├── style.css
├── script.js
│
├── images/
│   ├── profile.jpg
│   └── projects/
│
└── README.md
```

### `index.html`

Contains the main structure and content of the portfolio website.

### `style.css`

Contains the website's:

* Colours
* Fonts
* Background
* Layout
* Buttons
* Cards
* Animations
* Responsive design

Contains JavaScript used to add interactive features to the website.

## ▶️ How to Run the Website

### 1. Download or clone the project

Download the portfolio files to your computer.

### 2. Open the project folder

Make sure the HTML, CSS, JavaScript, and image files are in the correct folders.

### 3. Open `index.html`

Double-click:

```text
index.html
```

The website should open in your web browser.
